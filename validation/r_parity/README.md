# Parity and calibration checks against R

These scripts compare MannKS with independent references: the LWP-TRENDS R code
(v2502), run live through `Rscript`, `NADA::cenken`, exact permutation
distributions, and Monte Carlo simulation. They complement the unit tests. The
reference values used by `tests/test_lwp_parity.py` were generated by
`run_parity.py`.

| Script | What it checks |
|---|---|
| `kernel_parity.py` + `r_kernel.R` | R `GetKendal` / `GetInterObservationSlopes` vs MannKS (S, Var(S), censored Sen slope) on 300 random censored data sets |
| `run_parity.py` + `r_wrapper.R`, `r_seasonality.R` | R `MannKendall`/`SenSlope`/`SeasonalKendall`/`SeasonalSenSlope`/`SeasonalityTest` vs `trend_test`/`seasonal_trend_test`/`check_seasonality` in LWP mode: 29 synthetic edge cases plus the four LWP example data sets |
| `variance_truth.py` | Var(S) vs the exact permutation variance of S |
| `censored_slope_study.py` + `r_cenken.R` | ATS slope vs `NADA::cenken`, and bias of the censored slope estimators against a known slope |
| `regional_parity.py` + `r_regional.R` | `regional_test` vs R `getTAU` |
| `monte_carlo.py` | Type-I error, p-value uniformity, CI coverage, slope bias, fast-mode error, autocorrelation methods |

## Running

Requirements:
- R ≥ 4.3 with `plyr`, `tidyr`, `viridis`, `NADA`, `lubridate` and `gam`.
- The MannKS dependencies.
- The LWP-TRENDS sources (`LWPTrends_v2502.r` and `LWPTrends_ExampleData_v2502.rdata`), which are not distributed with MannKS.

```bash
export LWP_R=/path/to/LWPTrends_v2502/LWPTrends_v2502.r
./run_all.sh
```

Outputs are written to `out/`, which is not version-controlled. To evaluate a modified copy of the
package, point `MANNKS_SRC` at the directory that contains it.

## LWP mode

MannKS reproduces LWP-TRENDS with:

```python
common = dict(alpha=0.10, mk_test_method='lwp', ci_method='lwp', sens_slope_method='lwp',
              tau_method='a', tie_break_method='lwp')
mk.trend_test(x, t, agg_method='lwp', agg_period='month', **common)      # UseMidObs=TRUE
mk.seasonal_trend_test(x, t, season_type='month', agg_method='lwp', **common)
```

`alpha=0.10` matters because LWP-TRENDS reports 90% confidence intervals.

## Expected differences

With these settings every metric agrees to 1e-6 relative, apart from:

- **Cases where LWP-TRENDS declines to compute** (returns `NA` when a data-sufficiency
  note is raised, e.g. fewer than 5 non-censored values, an empty season, or a "long run").
  MannKS computes the result and reports the same note.
- **Same-day duplicate observations equidistant from an increment's mid-point.** R's choice
  depends on the row order produced by `merge()`; MannKS takes the first in time/input order.
- **Fast mode** (n > 5000 with `large_dataset_mode='auto'`), where the slope is estimated from a
  random sample of pairs. Use `large_dataset_mode='full'` for exact values.
- **ATS vs `NADA::cenken`.** MannKS returns the exact midpoint of the interval where S(β) = 0;
  NADA's bisection only approximates that interval's edges. The median difference is about
  0.3%.
